# BioHelix - Interactive DNA Visualizer

**Designed by Shanmukh**

An interactive molecular biology visualization tool featuring:
- 🧬 Immersive cellular zoom intro (Body → Cell → Nucleus → DNA → mRNA → Ribosome → Protein)
- 🔬 Three.js interactive 3D DNA Double Helix with mouse-drag rotation
- ⚗️ Real-time DNA Transcription & Translation simulator
- 🎨 Color-coded nucleotide base pairs (A=Blue, T=Cyan, C=Orange, G=Magenta)
- 🧪 Biological gene presets (Insulin, Hemoglobin, Collagen, Keratin)

## Run Locally

```bash
pip install -r requirements.txt
python app.py
```

Open `http://127.0.0.1:5000` in your browser.
